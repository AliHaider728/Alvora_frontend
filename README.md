# ALVORA Skincare - Frontend

A modern, high-performance e-commerce storefront and admin dashboard for **ALVORA Skincare**. This application is built to provide a premium, smooth, and highly responsive shopping experience for skincare products and curated routines.

## Tech Stack
- **Framework:** Next.js (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Analytics:** Meta Pixel (with CAPI support) & TikTok Pixel

## Key Features
- **Modern E-Commerce Storefront:** Beautifully crafted UI tailored for a premium skincare brand.
- **Product & Bundle Management:** Full support for single products, variations, and curated routine bundles (e.g., "The Glow Bundle").
- **Admin Dashboard:** Secure, integrated admin panel to manage orders, products, customers, and store settings.
- **Advanced Cart & Checkout:** Seamless sliding cart drawer and optimized checkout flow with Pakistani phone validation and shipping calculations.
- **Performance Optimized:** Utilizes Next.js Server-Side Rendering (SSR) and Static Site Generation (SSG) for lightning-fast page loads.
- **Responsive Design:** Mobile-first architecture ensuring perfect display across all devices.

## Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up your environment variables by creating a `.env` file in the root directory (reference `.env.example` if available).

### Development
Start the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Production Build
To create an optimized production build:
```bash
npm run build
npm start
```
